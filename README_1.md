# Dani's auto-site
My favorite part about having a website is just having the website, i dont want to spend weeks creating a website or a whole week updating it.
so naturally I spent even longer creating something i wouldnt need to touch again if i wanted to.

## Features
- Hugo SSG
  - all the benifits of the hugo static site generator (speed, security, etc) but without the complexity.
- Typst documents
  - Automatically generates your business card, Resume, etc. (update your phone number or other data and watch it update all your documents)
- Decap CMS
- Cloudflare workers
  - enables cart checkout, payment validation, automatically starting fulfillment process.
- Shop
  - Simple product catalog made of markdown files
  - Buy now using stripe payment links
