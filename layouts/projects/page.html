{{- /* A single project. Projects do not go through `section_map.html` the way an ordinary page does: like a service or a blog post, a project is one article rather than a stack of bricks, and what makes it one is where it lives, not what is written in it. So the `post` brick renders the page whole — the portfolio uses the services look — and the call to action the whole site closes on is added after it. That call to action is written once, in `content//bricks/cta.md`, and shared by every project. Its content has to go through `inline_attributes.html` here, because the page being rendered is not the one the markdown came from. */ -}} {{ define "sections" }} {{- partial "sections/post.html" (dict "Content" .Content "Name" "post" "Index" 0 "Page" .) -}} {{- with site.GetPage "/bricks/cta" -}} {{- partial "sections/cta.html" (dict "Content" (partial "inline_attributes.html" .Content) "Name" "cta" "Index" 1 "Page" $) -}} {{- end -}} {{ end }}
