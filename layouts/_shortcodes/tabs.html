{{- /* A tabbed panel. Each tab is a run of markdown opening on an `## Heading`, separated by `---` — the heading is the tab, the rest is its panel: {{< tabs >}} ## First tab Its content. --- ## Second tab More content. {{< /tabs >}} The `---` here never reaches `section_map.html`: the shortcode consumes its inner markdown before the page is split, so a tab boundary does not become a brick boundary. The tablist sits left by default; `center="true"` centres it, for an opener that is itself centred. The tablist is wrapped in its own `.container` so the rule under it runs the width of the content, not edge to edge. Neither does anything else the widget holds. A `jobs` or `services` listing inside a panel emits a `ul.posts`, which would otherwise route this whole section to the `posts` brick and hand it to `split_list.html` — and that splits a section at its first `
    ` and `
    `, tearing the tablist away from its panels. So `section_map.html` takes the widget out of a section before it tests the routing rules, recognising it as the `
    ` written below. A section that is nothing but a widget then routes to the `tabs` brick, `sections/tabs.html`. The widget is its own `
    ` for the same reason: with the `posts` and `collection` classes the existing card, tile and grid rules in `sections/posts.css`, `sections/tiles.css` and `style.css` style any listing a panel holds, and each panel is a `.container` so the grid's `section.collection > .container > ul` matches it. The `tabs` class is what `tabs.css` and `site.js` work on, and what `section_map.html` reads; the tablist is a `.container`-wrapped child and each panel a direct `.container`, so the `>` selectors there still hold. Revised from the original theme: real `role="tab"` buttons with the roving tabindex and `aria-selected` that `site.js` maintains, instead of ``; the script lives there rather than inline, and without it the panels simply stack under their own headings — the tablist only shows once the script has marked the widget `ready`. @context {shortcode} . */ -}} {{- $ordinal := .Ordinal -}} {{- $center := eq (.Get "center") "true" -}} {{- $parts := slice -}} {{- range $part := split .Inner "---" -}} {{- with trim $part "\n\r\t " -}} {{- $parts = $parts | append . -}} {{- end -}} {{- end -}} {{- if not $parts -}} {{- warnf "tabs: the shortcode on %q is empty — write `## Heading` runs separated by `---` inside it" .Page.File.Path -}} {{- end -}}
